# 貓糧資料

- `raw/momo_YYYY-MM-DD.txt`：momo 搜尋（依月銷量）盤點快照，每行 `i_code|dry/wet|排名|售價|品名`。
- `raw/momo_YYYY-MM-DD.json`：同上，加上品牌、總重、每公斤單價、處方標記（`scripts/inv.py` 產生）。
- `products_master_draft.json`：依品牌＋系列歸併的產品線草稿（`scripts/master.py` 產生），尚未人工確認。
- `ingredients/`：逐口味的成分、營養分析與熱量，每筆附來源網址與查證日期。
- `changes/YYYY-MM-DD.md`：每週價格與上下架變動摘要。

## 資料結構
產品線（品牌＋系列）→ 口味／配方（成分、營養、熱量、主要蛋白來源）→ 規格（重量、包數、價格）。
成分與熱量記在口味層；價格記在規格層。同系列其他口味的資料不互相頂替，除非品牌官方註明全系列同一配方。

## 成分查證順序
1. momo 商品頁（文字或規格圖）
2. 品牌官網
3. 其他電商（PChome、蝦皮商城、寵物通路等）
4. Google 圖片搜尋包裝實品圖（營養分析與成分表要清楚可讀）

四個來源都查不到完整標示 → `status: "unverified"`，網站顯示「成分以商品頁為準」標籤，不參與營養排名。
